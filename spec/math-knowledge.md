# Conocimiento de las ocho asignaturas

Escrito al abrir la fase 29. El contrato vivo está en `roadmap.md`.

Ocho asignaturas tenían lección y ninguna carta: `poo`, `automatas`, `adquisicion`, `redes`, `bases`, `infra`, `distribuidos`, `software`. Cada una enlaza al menos cuatro cartas del banco. Las lecciones que ya estaban se conservan. Las 96 cartas anteriores no se reescriben.

La respuesta de test y el paso de estudio salen de `entrenador-matematicas/src/data/knowledge/checks.ts`. El test de conocimiento recalcula esa respuesta con otro procedimiento y la compara con la carta. No se copia el texto esperado a mano.

La interfaz no muestra créditos ni códigos de asignatura.

| Id | Qué practica la carta |
| --- | --- |
| `poo` | Acumular en un objeto, no tocar al otro, cambiar el ancho y dejar el alto. |
| `automatas` | Longitud de una cadena y aceptar solo si acaba en 1. |
| `adquisicion` | Cuántas muestras caben en un tiempo y un periodo. |
| `redes` | Saltos entre paradas y segundos de una transferencia. |
| `bases` | Filas con un valor, una clave que aparece una vez y valores distintos. |
| `infra` | Partes iguales, el resto y un lote que no se parte. |
| `distribuidos` | El emisor conserva su valor y el receptor recibe una copia. |
| `software` | Un caso pasa si el valor es el esperado, y dos casos pasan solo si pasan los dos. |
